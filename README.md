# 🏭 Employee Suggestion Scheme – Full Stack Web Application

A **full stack web application** developed for **Rashtriya Ispat Nigam Limited (RINL) – Vizag Steel Plant** to digitize and streamline the employee suggestion and feedback process.  
This system replaces the traditional manual, paper-based workflow with a **secure, transparent, and database-driven digital platform**.

---

## 📖 Project Overview

The **Employee Suggestion Scheme** enables employees to:
- Log in using unique employee credentials
- View personal details (name, designation, department, age)
- Submit structured suggestions through an interactive web interface

All suggestions are stored securely in a **MySQL database**, allowing efficient tracking, review, and management.  
The application follows a **layered MVC architecture**, ensuring scalability, maintainability, and clean separation of concerns.

This project demonstrates real-world **full stack development** in an industrial environment using modern web technologies.

---

## ✨ Key Features

- 🔐 Secure employee login system  
- 🧾 Interactive suggestion submission form  
- 🗄️ Centralized MySQL database storage  
- ⚡ REST API–based frontend–backend communication  
- 📱 Responsive and user-friendly UI
